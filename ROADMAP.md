# Roadmap

- Semantic, responsive single-page site
- Mobile navigation and keyboard support
- Portfolio filtering and native project details dialog
- Accessible testimonial carousel
- Browser-side contact form validation
- Local SVG assets and reduced-motion support
- SEO metadata and GitHub Pages deployment workflow
- Static repository validation tests
- Apache-2.0 licensing
- Nuru Tech public contact details
- Endpoint-ready contact form integration
- Playwright and axe-core browser testing setup

- Add a maintainable content model if the site expands
